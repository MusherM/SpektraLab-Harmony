# SpektraLab 1.1.0 release notes

Release date: November 11, 2026 (Beijing time). Previous release: **1.0.0**.

[中文](1.1.0.md)

- **Photo preview colors:** Fixed incorrect brightness and colors after importing some JPEG, PNG and other images with embedded color profiles.
- **Transparent image previews:** Fixed additional darkening when previewing PNG and WebP images with transparency.
- **RAW original previews:** Adjusted display exposure to each photo's brightness distribution, improving dark previews from some cameras while retaining the original linear data for film processing.
- **RAW import stability:** Fixed crashes that could occur after repeated RAW imports, returning from settings or importing again after an idle period.
- **Save-time explanation:** A question mark appears when saving takes more than three seconds. An open explanation stays visible after saving finishes; tap the text or elsewhere on the screen to dismiss it.
- **Credits animation:** Improved the transition out of the full-screen credits animation and fixed the white fade.
