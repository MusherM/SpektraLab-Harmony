# SpektraLab 0.4.0 更新说明

发布日期：2026 年 11 月 5 日（北京时间）。以下为自 0.3.0 以来的变化。

- **更快导入**：导入照片后直接显示原图，胶片与相纸初始均为“未选中”；导入过程显示“正在导入”。优化 RAW 多线程解码与预览转换，缩短等待时间。
- **按需冲印**：选择胶片或相纸后，另一项自动补齐默认材料并开始冲印，启用调整、相框和保存；选择“未选中”会同时清空两项并恢复原图。
- **保存提速**：复用 RAW 解码结果与渲染引擎，减少保存时的重复处理。
- **保存说明**：保存超过 3 秒后，文字右侧平滑出现灰色圆圈问号，点击可查看处理耗时说明；保存提示保持居中，问号与文字行高一致。
- **统一配色**：导入菜单与相册选择器采用深色配色，与应用主题保持一致。
