# SpektraLab 0.3.0 更新说明

发布日期：2026 年 11 月 5 日（北京时间）。以下为自 0.2.0 以来的变化。

- **RAW 导入**：修复 RAW 照片解码与导入问题，完善相机 RAW 格式识别和处理。
- **相册选图**：新增「全部 / RAW」筛选、图像格式说明和缩略图选中标记；选定原图后点击「使用照片」进入冲印。
- **文件导入**：在「导入」菜单新增「从文件选择」，可直接选择文件中的照片和 RAW 原片。
- **输出格式**：设置中新增 JPEG、PNG 和 HEIF 选项，并记住选择；HEIF 根据设备编码能力启用。
- **原图保存**：优化全尺寸照片的分块冲印处理，修复长时间冲印后保存到相册的授权时序问题；保存时校验成片格式、尺寸和写入后的文件大小。
