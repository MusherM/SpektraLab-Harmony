# SpektraLab 1.2.0 release notes

Release date: November 12, 2026 (Beijing time). Previous release: **1.1.0**.

[中文](1.2.0.md)

- **More intuitive exposure adjustment:** Exposure changes affect the finished photo's brightness more directly. Move right to brighten and left to darken. Preview rendering and full-resolution saving both use the new exposure processing.
- **A range for finer adjustments:** Exposure now ranges from **-3 to +3 EV**. The default remains **0 EV**, with one-tap reset.
